# Altium Designer 封装库

本仓库收录了常用电子元器件的 Altium Designer 封装，方便项目开发与复用。

## 封装分类

| 分类            | 中文说明                 |
| --------------- | ----------------------- |
| **Buzzer**      | 蜂鸣器                  |
| **CAN_IC**      | 控制器局域网芯片        |
| **Connector**   | 连接器                  |
| **Crystal**     | 晶振                    |
| **Flash**       | 闪存芯片                |
| **Gate_Driver** | 栅极驱动器              |
| **IMU**         | 惯性测量单元            |
| **LDO_DCDC**    | 低压差线性稳压器与DC-DC |
| **MCU**         | 微控制器单元            |
| **MPU**         | 微处理器单元            |
| **OLED_LCD**    | 显示屏（OLED/LCD）      |
| **RC**          | 电阻电容元件            |
| **Serial_IC**   | 串行通信芯片            |
| **Switch**      | 开关器件                |
| **Transistor**  | 晶体管                  |
